## Overview

KINTSUGI is an AI-powered data analysis application that helps users clean, explore, visualize, and understand datasets with minimal manual effort.

The application combines data preprocessing, interactive visualizations, automated reports, and AI-generated insights to make data analysis faster and more accessible.

---

## Features

- Upload CSV datasets
- Automatic data cleaning
- Missing value handling
- Duplicate detection and removal
- Data quality reporting
- AI-generated insights
- Interactive charts
- PDF report generation
- Dataset summary
- Intelligent preprocessing
- Chat-based AI analysis

## Installation

Clone the repository:

```bash
git clone https://github.com/shreyaa2104/KINTSUGI.git
```

Move into the project:

```bash
cd KINTSUGI
```

Create a virtual environment:

```bash
python -m venv env
```

Activate it.

Windows:

```bash
env\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run apps/kintsugi.py
```
